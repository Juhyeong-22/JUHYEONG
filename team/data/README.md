## 계산 방법

- 업소 수: 그해 1월 1일 영업 중인 일반음식점 + 휴게음식점 수. 2026년 값 = 2025년 1월 1일 업소 수 + 2025년 개업 − 2025년 폐업.
- 행정동과 상권 대응 (내가 정한 것, 경계 일치 여부는 미확인)
  - 전남대 → 용봉동, 조선대 → 서남동, 구시청 → 충장동, 첨단 → 첨단1·2동
- '다음 동명동' 점수 = 아래 3개 지표의 z점수 합
  1. 업소 수 증가율 (2021년 1월 → 2026년 1월)
  2. 휴게음식점(카페 등) 수 증가율 (같은 기간)
  3. 2024~2025년 순증률 = (개업 − 폐업) ÷ 2024년 1월 1일 업소 수
  - 대상: 2021년 업소 50~300곳인 68개 동 (동명동이 성장 초기에 이 규모였음)
  - 한계: 업소 수가 적은 동은 몇 곳만 늘어도 증가율이 크게 나온다. 신규 택지 개발 영향은 걸러내지 않았다.
