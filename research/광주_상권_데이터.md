# 광주 상권 데이터 조사노트

- 대상 상권: 구시청, 첨단, 동명동, 상무지구
- 조사일: 2026-11-12
- 방법: 웹 검색 후 ego-browser로 한국부동산원 부동산통계정보시스템(R-ONE) 통계표와 소상공인365 간단분석 리포트를 열어 수치를 읽음
- 2026년 3분기부터 부동산원 통계가 '전남광주' 권역으로 묶여 새 표로 나왔다. 2024년 3분기~2026년 2분기 표와 지역 체계가 달라 시계열을 이어 볼 때 주의해야 한다.

## 데이터별 구할 수 있는지

| 항목 | 구할 수 있나 | 단위 | 대상 상권 커버 | 출처 |
|---|---|---|---|---|
| 공실률 | 가능 | 분기, 상권 | 상무지구, 첨단1·2지구, 금남로/충장로 O. 동명동, 구시청은 별도 상권으로 없음 | R-ONE 상업용부동산 임대동향조사 |
| 상가 권리금 | 가능 (광주 전체만) | 연, 시도·업종 | 상권별 수치 없음 | R-ONE 시도별/업종별 상가권리금 |

| 업소 수 증감 (신규 입점 대용) | 가능 (업종별 순증감만) | 월, 행정동·업종 | 위와 같음 | 소상공인365 간단분석 |
| 개업률·폐업률 | 미확인 | - | - | 간단분석에는 없음. 리포트에 '자세한 상권분석정보는 상세분석 서비스를 이용'하라고 나옴 (로그인 필요 여부 미확인) |

- 구시청: 부동산원 상권 목록에 '구시청'은 없다. 가까운 상권은 '금남로/충장로'인데, 구시청 일대가 이 상권 범위에 들어가는지는 확인 안 했다. → 미확인
- 동명동: 부동산원 상권 목록에 없다. 소상공인365에서는 행정동 '동명동'으로 볼 수 있다.
- 소상공인365는 행정동 단위라 상권과 경계가 다르다. 이 노트에서는 상무지구 → 치평동·상무1동, 첨단 → 첨단1동·첨단2동, 구시청 → 충장동으로 대응시켰다. 이 대응은 내가 정한 것이고, 각 상권이 행정동 경계와 정확히 맞는지는 확인 안 했다. 특히 구시청 일대가 충장동에 속하는지는 미확인이다.

- '-'는 통계표에 해당 상권 행이 없다는 뜻이다.
- 상무지구는 중대형 상가 공실률(22.3%)이 높은데 1층 공실률은 4.8%로 낮다.
- 소규모 상가 0.0%는 조사 대상 건물에 공실이 없었다는 뜻이다. R-ONE FAQ에 '상권 공실률 0%' 해석 항목이 따로 있어, 표본이 작을 수 있으니 해석에 주의해야 한다.
- 광주 안에서 공실률이 가장 높은 상권(중대형 기준)은 전남대 39.6%, 어룡동 37.6%다.

## 6. 아직 못 구한 것

- 개업률·폐업률: 소상공인365 상세분석에 있을 것으로 보이지만 확인 안 했다.
- 지방행정 인허가 데이터(LOCALDATA)로 업소별 개업일·폐업일을 집계하는 방법도 아직 확인 안 했다.
- 광주 동구 자체 공실·유동인구 조사(충장로)는 검색 결과에서만 봤고 원문은 열지 않았다.
